# 전투 이펙트 에셋 — 넣어야 할 파일 명세

`static/js/SkillFx.js`의 **배선은 끝나 있다** — 스킬 65종이 전부 계열에 매핑돼 있고
(미매핑 0), 14개 계열이 전부 실제로 쓰인다. 각 계열의 `src`가 빈 문자열이라 지금은
이펙트가 그냥 안 나올 뿐, 코드는 그대로 두고 **파일만 넣으면 켜진다.**

## 넣는 방법

1. 아래 표대로 스프라이트 시트를 이 디렉터리에 둔다.
2. `static/js/SkillFx.js`의 `FX_FAMILY` 표에서 해당 계열의 `src`를 `'img/fx/<파일명>'`으로 채운다.
3. 프레임 수/fps가 표와 다르면 `frames`/`fps`도 같이 고친다 — `BattleSequencer.js`가
   대기 시간을 `frames/fps`로 계산하므로 값이 어긋나면 애니메이션이 잘리거나 겹친다.

가로로 이어 붙인 1행 시트를 전제로 한다(총 너비 = `frameW × frames`, 높이 = `frameH`).
배경은 투명 PNG. `blend: screen`인 계열은 검은 배경이 그대로 지워지도록 밝은 픽셀만 남긴다.

## 주의

- 에셋 파일 자체는 **커밋 보류 대상**이다(스프라이트·전투 이펙트 규칙). 이 README만 추적한다.
- `dot` 계열은 한 시트를 `DOT_FX`가 tint로 재사용한다 — 출혈은 붉게, 물리 균열은 회색.
  색을 시트에 굽지 말고 **흰색~밝은 회색 기준**으로 만들어야 tint가 먹는다.
- 상위 티어(파이어볼2 등)는 새 시트를 만들지 않고 `scale`로 키운다. 계열당 1장이면 된다.
